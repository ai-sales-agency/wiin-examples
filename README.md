# wiin.agency — examples

Минимальные, самодостаточные примеры кода к статьям [wiin.agency](https://wiin.agency).

Мы внедряем ИИ-агентов в отделы продаж (квалификация лидов, обработка заявок 24/7, follow-up) и пишем про то, что реально крутится у нас в проде. Каждая папка здесь — companion-код к конкретной статье: упрощённый, но рабочий extract нашего стека, без проприетарной части и секретов.

| Папка | Статья |
|---|---|
| [llm-router](./llm-router) | Пять LLM-провайдеров через один openai-клиент: роутер с fallback |
